```javascript

function validateWorkoutData(data) {
  return data.keys().hasAll(['date', 'duration', 'type'])
    && data.duration is number
    && data.duration >= 1
    && data.duration <= 1440
    && data.date is string
    && data.type is string
    && data.type.size() <= 50;
}
```

## New Security Findings

### 🟡 P2-001: Console Logging in Production
**Severity:** Medium  
**Location:** Throughout application, controlled by log capture system  
**Risk:** Information disclosure

**Analysis:**
The application includes a sophisticated log capture system (`src/lib/utils/logCapture.ts`) that intercepts console logs. While this is useful for debugging, it may capture sensitive information.

**Findings:**
- Log capture system stores all console output
- Logs can be exported via keyboard shortcut (CTRL+SHIFT+L)
- Production builds may still include console statements

**Recommendations:**
1. Add environment-based log filtering
2. Sanitize log output in production
3. Implement log rotation/cleanup

### 🟡 P2-002: Error Handling Information Disclosure
**Severity:** Medium  
**Location:** `src/lib/utils/errorHandling.ts`  
**Risk:** Information leakage through detailed error messages
